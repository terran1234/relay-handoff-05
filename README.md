# relay-handoff-05 — 대화가 끊겨도 이어지는 프로젝트 (과제 5)

과제 4 [daily-board-04](https://github.com/terran1234/daily-board-04)의 작은 개선 하나("기록 요약: 최고·최저·평균")를 **AI A가 시작하고, 인수인계 문서를 남기고 멈추면, 완전히 새로운 AI B가 저장소와 인수인계 문서만으로 이어서 같은 검사 10개를 통과**시키는 실험의 기록 저장소입니다.

## 짧은 확인 방법 (4줄)

① 위치: https://terran1234.github.io/relay-handoff-05/ (로그인 없이 열림)
② 3단계 이내 행동: 1) 맨 위 "가린 비교표"를 봅니다 → 2) 2절의 "비교" 링크로 A·B 시작·종료 버전 차이를 엽니다 → 3) 소스 저장소의 `b-results.md`에서 검사 10개 결과를 확인합니다.
③ 통과 모습: 표에 두 AI의 시간·요청·오류 회차·통과 수가 모두 있고 B가 10/10, `b-results.md`에도 V01~V10 모두 PASS가 보입니다.
④ 안 될 때 모습: 합계가 7/10처럼 줄고 FAIL 줄이 빨갛게 나옵니다. 로컬에서 `t05-check.html`을 서버 없이 파일로 열면 요약 칸이 비거나 "기록을 불러오지 못했습니다"가 보입니다.

## AI와 나의 판단 (3줄)

- AI에게 맡긴 일: 저장소와 문서 작성, 기능 코드(앞부분은 AI A, 남은 V07·V09·V10은 AI B), 검사 10개를 한 번에 돌리는 페이지, 새 폴더 재현과 문서 지문 대조, 비교 페이지 작성.
- 직접 판단한 일: 과제용 저장소를 새로 만들고 이름 형식을 맞추기로 한 것, 두 번째 AI로 다른 서비스를 쓰기로 한 것, AI가 제안한 개선 주제와 검사 10개로 진행하기로 한 것, 두 번째 AI에 직접 글을 붙여넣고 시각과 답을 전달한 것, 설명을 먼저 하고 묻지 말고 한 단계씩 하라고 진행 방식을 정한 것.
- AI 제안을 따르지 않은 일: AI는 AI A를 새 대화에서 따로 시작하는 쪽을 권했지만 나는 이 대화에서 그냥 진행하라고 했다. 그래서 AI A는 준비 과정을 이미 알고 있었고, 이것이 이 비교의 한계다.
